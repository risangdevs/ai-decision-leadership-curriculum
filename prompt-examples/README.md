# Prompt Examples

This folder contains reusable prompts for running the **Data-Driven & AI-Enabled Decision Making** curriculum as an interactive, case-based learning program.

## Available prompts

| File | Description |
|---|---|
| [Phase 1 — Decision Leadership Foundations](phase-1-decision-leadership-foundations.md) | Modules 1–2: AI decision suitability, human oversight, root-cause analysis, and decision framing. |
| [Phase 2 — Decision Making with Data Framework](phase-2-decision-making-with-data-framework.md) | Modules 3–7: analytical thinking, data structure, metrics, experiments, and AI-enabled execution. |
| [Phase 3 — Leveraging AI for Decision Making](phase-3-leveraging-ai-for-decision-making.md) | Modules 8–13: AI systems, assistants, workflows, analytics, market intelligence, and business cases. |
| [Phase 4 — Institutionalizing AI](phase-4-institutionalizing-ai.md) | Modules 14–16: organizational habits, executive simulation, governance, economics, and the final capstone. |

## How to use the prompts

1. Open the prompt file for the phase you want to study.
2. Copy the complete prompt inside its fenced `text` block.
3. Paste it into a new ChatGPT chat in the same Project.
4. Follow the tutor's questions one at a time and complete the requested exercises, assessments, and artifacts.
5. At the end of the phase, ask for the specified **Learning Transfer Package** if the tutor has not already produced it.
6. Start a separate chat for the next phase, paste its master prompt, and then provide the previous phase's Learning Transfer Package when requested.

## Recommended chat structure

Create four chats and complete them in order:

1. **Phase 1 — Decision Leadership Foundations** (Modules 1–2)
2. **Phase 2 — Decision Making with Data Framework** (Modules 3–7)
3. **Phase 3 — Leveraging AI for Decision Making** (Modules 8–13)
4. **Phase 4 — Institutionalizing AI** (Modules 14–16)

Keeping the phases in separate chats limits context growth while the transfer packages preserve continuity between phases.

## Usage notes

- Complete each phase sequentially; later prompts expect the preceding phase's transfer package.
- Keep your answers, tutor feedback, scores, and completed artifacts in the relevant chat or save them in separate Markdown files.
- Replace or supplement fictional cases with your own organizational context only when sharing that information is appropriate.
- Do not paste confidential, personal, regulated, or security-sensitive information into a chat without authorization and suitable safeguards.
- Verify current laws, standards, product capabilities, source links, and technical documentation before relying on them in operational decisions.
- Treat the prompts as educational scaffolding. They do not replace qualified legal, financial, security, compliance, or other professional advice.

## Customizing a prompt

You can add a short context section before `BEGIN NOW` to specify your role, industry, preferred case domain, available tools, accessibility needs, or weekly study schedule. Avoid removing the assessment gates, source-verification requirements, human-oversight controls, or phase handoff instructions unless you intentionally want to change the learning design.
